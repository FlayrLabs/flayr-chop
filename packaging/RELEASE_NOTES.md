Flayr Chop: a free, open-source sample chopper with on-device stems and HQ Stretch.

- Auto tempo, beat grid, key and transient detection; auto-chop to up to 64 pads in 4 banks
- Stem separation on your computer (Demucs v4), stems selectable per pad
- Independent key and tempo with high-quality stretching, formant preservation, half/double-time aware host sync
- Keys mode with every note time-corrected, launch quantize, drag pads out to the DAW, export track / stems / slices

The stem model (84 MB) downloads on first use. See the README for install steps.
